# Word Quest — техническое задание и сценарий игры

> Инструкция для Claude. Это браузерная обучающая RPG для детей K3 (5–6 лет) в детском саду в Бангкоке.
> Автор и заказчик — учитель (Teacher Sam). Весь текст и озвучка в игре — **на английском**.
> Общение с автором — на русском.

---

## 1. Суть

Ребёнок управляет героем на изометрической карте (вид как в Diablo), бегает и собирает буквы, чтобы составить **одно заданное слово за сессию**. Часть букв лежит на земле, часть заперта в сундуках, которые открываются решением простого примера на сложение/вычитание. Есть бонусный подземный уровень, безобидные мобы и «живая» карта.

**Цель обучения:** запоминание английских слов и их написания, узнавание букв, счёт до 30.

---

## 2. Платформа и условия

- Играют на **обычном Windows-компьютере**, изображение выводится **через проектор** на весь класс. Учитель рядом и руководит процессом.
- Браузер: Chrome / Edge, полноэкранный режим (кнопка Fullscreen).
- Управление — три способа, работают одновременно (подробно в разделе 2.1).
- Всё крупное и контрастное — смотрят с проектора издалека. Шрифты буквы/слова — очень крупные.
- Публикация: репозиторий **Sounger/kids-games** на GitHub Pages (отдельная папка игры), работает по ссылке без установки.
- **Таймера нет.** Проигрыша нет. Темп регулирует учитель.

### 2.1. Управление

Все три способа активны одновременно, переключать ничего не нужно.

**Геймпад (основной для детей)** — IINE Gamebrick Mini Retro Controller: только **крестовина + A + B**. Вся игра должна полностью проходиться этими тремя кнопками.
- Подключение: Bluetooth к Windows в режиме **X-input**; в браузере через **Gamepad API** (опрос `navigator.getGamepads()` в игровом цикле).
- Браузер видит геймпад только после первого нажатия → на стартовом экране надпись **"Press A to start"** и индикатор «геймпад подключён».
- **Крестовина** — движение. В изометрии каждое направление крестовины = движение по диагонали экрана (вдоль осей изометрической сетки), чтобы ходить «по клеткам» было интуитивно.
- **A** — действие: подобрать букву, открыть сундук, поговорить с совой, войти в люк, подтвердить ответ, `PLAY`.
- **B** — «хлопок» (отпугнуть слайма); в окнах — назад/закрыть.
- В окне примера: крестовина ←/→ (и ↑/↓) выбирает вариант ответа (выбранная кнопка сильно подсвечена), A — подтвердить.
- Авто-действие: если герой стоит вплотную к букве — подбирается сама, без нажатия A.
- Надёжная обработка: маппинг стандартного layout (кнопки 0/1, d-pad 12–15) + запасной вариант через оси, если d-pad приходит как axes. Дебаунс нажатий.

**Клавиатура**
- WASD / стрелки — движение; Space / Enter — действие (как A); X / Backspace — «хлопок»/назад (как B).
- **Esc — пауза.** Меню учителя открывается только с клавиатуры/мыши (у геймпада нет кнопки Start, и детям туда не нужно).

**Мышь**
- Клик по земле — идти туда (как в Diablo, с поиском пути в обход препятствий).
- Клик по объекту (буква, сундук, сова, люк) — подойти и взаимодействовать.
- Клик по вариантам ответа в окне примера.

## 3. Визуальный стиль

- **Изометрия**, качественная **пиксельная графика в высоком разрешении** (чёткие пиксели, `image-rendering: pixelated`, масштабирование кратно целому, без размытия).
- Целевое разрешение 1920×1080 (проектор), корректно масштабируется под окно.
- Яркая, дружелюбная палитра, ничего страшного.
- Графика: рисуется кодом (процедурные пиксельные спрайты на canvas) или берётся из бесплатных ассетов с лицензией CC0 (например, изометрические паки Kenney). Никаких защищённых персонажей.
- Буквы на карте — крупные объёмные пиксельные буквы, мягко подпрыгивают и светятся, чтобы их было видно.

Рекомендуемый стек: **Phaser 3** (через CDN) или чистый Canvas — на усмотрение Claude, главное плавность и простота деплоя на GitHub Pages.

## 4. Игровой цикл

1. **Стартовый экран:** название игры, кнопка `PLAY`, скрытый вход в меню учителя.
2. **Показ слова:** крупно слово + картинка. Голос (Web Speech API, английский) произносит слово, затем по буквам, затем снова слово: *"Apple. A-P-P-L-E. Apple!"*
3. **Загрузка карты** (надземный уровень).
4. **Интерфейс во время игры:**
   - **Сверху экрана** — полупрозрачная затемнённая плашка, на ней написано целевое слово (подсказка-образец).
   - **Снизу экрана** — ячейки-прочерки по числу букв: `_ _ _ _ _`.
   - Кнопка-динамик рядом со словом — повторить произношение.
5. **Сбор букв — в любом порядке.** Ребёнок берёт ту букву, которую нашёл. Буква озвучивается (*"P!"*), летит по дуге вниз и встаёт **в свою правильную ячейку**. Если буква в слове повторяется (две P в APPLE), она занимает первую свободную подходящую ячейку.
6. **Финал:** все ячейки заполнены → праздник: салют/конфетти, герой прыгает, слово звучит целиком (*"Great job! APPLE!"*), экран победы со звёздами. Кнопка `PLAY AGAIN` (то же слово или следующее по списку — выбирает учитель).

---

## 5. Надземный уровень (основной)

- Изометрическая карта среднего размера (камера следует за героем), с лугом, деревьями, речкой с мостиком, тропинками, камнями, цветами, домиком.
- Буквы целевого слова распределяются так (пропорции настраиваются):
  - **~50–60 % лежат на земле** — подошёл и собрал.
  - **~40–50 % заперты в сундуках.**
  - Иногда одна буква может оказаться под землёй (см. раздел 7), но **всё слово всегда собирается на поверхности** — подземелье не обязательно.
- Расстановка случайная при каждом запуске, но с проверкой, что все буквы достижимы.

### 5.1. Буквы-обманки
- На карте лежат несколько букв, **которых нет в слове** (или лишние копии). Количество задаётся в настройках, можно выключить.
- Когда герой подбирает обманку: буква дрожит, становится серой/красноватой, с забавным звуком «бульк/пуф» отскакивает и исчезает. Над героем появляется облачко, голос говорит: *"Oops! We don't need Z. We need P, L, or E!"* (называет недостающие буквы).
- Никаких штрафов.

---

## 6. Сундуки с примерами

- Клик по сундуку → окно с примером крупным шрифтом, например `14 + 9 = ?`, голос читает: *"Fourteen plus nine?"*
- **3 варианта ответа кнопками** (ввод с клавиатуры не нужен).
- **Правильно:** *"Correct!"*, сундук открывается с искрами, буква вылетает и сразу летит в свою ячейку.
- **Неправильно:** сундук трясётся, *"Try again!"*, неверный вариант исчезает (остаётся 2, потом 1 — ребёнок никогда не застревает).
- Правила генерации:
  - сложение и/или вычитание (настройка);
  - все числа и результат в диапазоне **0…max** (по умолчанию 30, можно 10 или 20);
  - вычитание без отрицательных результатов;
  - неправильные варианты близки к правильному (±1…±3), не повторяются, в диапазоне.

---

## 7. Подземный бонусный уровень

- Вход: **люк / нора / вход в пещеру** где-то на карте. Голос/сова намекает: *"I see a secret hole!"*
- Внутри: тёмная пещера, видно только круг света вокруг героя (не страшно — светлячки, кристаллы, светящиеся грибы).
- Что там:
  - **кристаллы/звёзды** — бонусные очки на экране победы;
  - **золотая буква** (не всегда) — сама ставится в одну из пустых ячеек слова. Помощь для тех, кто застрял;
  - иногда сундук с примером.
- Выход — лестница наверх, герой появляется у того же люка.
- Подземелье можно отключить в настройках.

---

## 8. Мобы (без насилия)

Никаких смертей, здоровья и game over. Максимум — «уронил букву».

- **Енот-воришка** — бродит, если коснётся героя, выбивает одну собранную букву: она выпрыгивает из ячейки и падает рядом на землю, её можно снова подобрать. Енот убегает с хихиканьем. После этого какое-то время не пристаёт.
- **Слаймы** — медленно ползают возле некоторых сундуков. Касание — герой отскакивает. Отпугнуть можно кнопкой «хлопок» (пробел / правый клик): слайм пугается и отползает.
- **Пчела** — летает по кругу у цветов, если коснётся — герой ненадолго замедляется (смешная анимация).
- Мобы включаются/выключаются в настройках; их количество небольшое (2–4 на карту).

---

## 9. Живая карта

- Колышущаяся трава, бегущая вода в речке, бабочки, птицы, пролетающие облачка (тени на земле).
- **Сова-помощник (NPC):** подходишь — даёт подсказку, где ближайшая нужная буква: *"The letter L is near the river!"*
- Цветы распускаются на месте подобранной буквы — видимый след прогресса.
- Мягкие фоновые звуки (ветер, птицы) и чиптюн-саундтрек (раздел 11); кнопки mute для музыки и звуков отдельно.
- Опционально: лёгкий дождик или вечерний свет как случайная погода.

---

## 10. Меню учителя (Teacher Mode)

- Вход: **долгое нажатие на иконку шестерёнки** (3 сек) или простой пароль — чтобы дети не заходили.
- **Список слов:**
  - добавить / изменить / удалить слово (только латинские буквы, длина 2–10);
  - картинка к слову: эмодзи или загруженное изображение;
  - **наборы по темам** (Fruits, Animals, Colors…), активный набор выбирается перед игрой;
  - режим выбора слова: по порядку / случайно / вручную перед стартом.
- **Настройки:**
  - диапазон чисел: 10 / 20 / 30;
  - операции: только `+` / только `−` / оба;
  - доля букв в сундуках;
  - обманки: вкл/выкл + количество;
  - мобы: вкл/выкл;
  - подземелье: вкл/выкл;
  - громкость голоса, скорость речи, музыка.
- Хранение: `localStorage` + **экспорт/импорт в JSON-файл** (чтобы переносить слова между Mac и рабочим Windows).

---

## 11. Звук и голос

- Озвучка: **Web Speech API**, английский голос (выбрать en-US/en-GB, если доступен), скорость чуть ниже обычной.
- Фразы: название буквы при подборе, слово целиком, условие примера, *"Correct!"*, *"Try again!"*, *"Oops! We need…"*, *"Great job!"*.
### 11.1. Музыка — 8-бит, генерируется кодом
- Саундтрек в стиле **8-бит (NES / Dendy)**, синтезируется прямо в коде через **Web Audio API** — никаких аудиофайлов.
- Каналы как на NES: 2 × square (мелодия и гармония, с разной скважностью 12.5/25/50 %), triangle (бас), noise (ударные).
- Простой встроенный трекер/секвенсор: паттерны нот в JS-массивах, темп, луп.
- Треки:
  - **Title** — бодрая короткая тема стартового экрана;
  - **Overworld** — весёлая, не навязчивая, зацикленная (основная музыка поверхности, 60–90 сек до повтора);
  - **Cave** — загадочная, тише, с эхом (подземелье);
  - **Victory** — короткий джингл победы;
  - **Chest** — короткий джингл открытия сундука.
- Плавные кроссфейды между треками. Музыка тише голоса — озвучка всегда важнее.
- Архитектура такая, чтобы позже можно было **заменить любой трек на внешний файл** (mp3/ogg, сделанный автором в Ableton) без переделки кода — например, через конфиг `music: { overworld: null | "music/overworld.ogg" }`.
- Браузер запускает звук только после первого действия пользователя — стартовать аудио по "Press A to start".

### 11.2. Звуковые эффекты
- Короткие весёлые чиптюн-эффекты, тоже синтезом: шаги, подбор буквы (восходящее арпеджио), обманка («бульк» вниз), сундук трясётся, сундук открылся, хлопок, енот хихикает, вход в пещеру, салют.

---

## 12. Принципы для K3

- Ребёнок **не может проиграть или застрять**: ошибки только смешные, всегда есть подсказка.
- Минимум текста на экране, кроме самого слова и чисел. Всё важное — озвучено.
- Крупно, ярко, контрастно — видно с проектора.
- Никаких страшных образов, крови, оружия.

---

## 13. Порядок разработки

1. Изометрическая карта + герой + управление (геймпад, клавиатура, мышь) + камера.
2. Слово, плашка сверху, ячейки снизу, сбор букв в любом порядке → в правильные ячейки, экран победы.
3. Озвучка + базовые звуковые эффекты.
4. Сундуки с примерами.
5. Обманки.
6. Меню учителя + сохранение + экспорт/импорт.
7. Мобы.
8. Живая карта: анимации, сова, фоновые звуки.
9. 8-битный саундтрек (секвенсор + треки).
10. Подземный уровень.
11. Полировка графики, деплой на GitHub Pages.

## 14. Как работать (для Claude в этом проекте)

- Этот файл — главный документ. Делай игру по нему, этап за этапом из раздела 13.
- **После каждого этапа — рабочая версия**, которую автор может открыть и проверить (в том числе с геймпадом). Коротко скажи, что сделано и как проверить.
- Не начинай следующий этап, пока автор не подтвердил текущий, если он не попросил делать несколько сразу.
- Код держи модульным: отдельно карта, герой, ввод, слово/UI, сундуки, мобы, аудио, меню учителя, конфиг. Все настройки по умолчанию — в одном конфиге.
- Без серверной части: только статические файлы для GitHub Pages; внешние библиотеки — только с CDN.
- Проверяй, что всё читается с проектора: крупно, контрастно, без мелкого текста.
- Если что-то в задании противоречит здравому смыслу для детей 5–6 лет или технически плохо работает — скажи и предложи вариант, а не делай молча.
- Общение с автором — на русском; всё внутри игры — на английском.
